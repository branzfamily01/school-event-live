# School Event Live

文化祭・体育祭・学校説明会などを、準備期間から当日、終了後まで育てていけるイベント特設サイトです。

## 公開起点
`index.html`

## 主な編集箇所
- `content.js` : イベント日時、記事、企画、ギャラリー
- `assets/` : 写真・画像
- `style.css` : デザイン

## GitHub Pages
このフォルダの中身をリポジトリのルートへ置き、`main` ブランチから GitHub Pages を公開してください。

## 次段階
iPhoneから直接記事・写真を投稿できるCMSを追加する場合は、Supabase等のバックエンドを接続できます。
